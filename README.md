# Dataset Destinasi Wisata dan Kuliner Banyuwangi
Dataset terkait destinasi wisata dan kuliner di wilayah Kabupaten Banyuwangi, Jawa Timur. Dataset ini dikumpulkan sejak tahun 2025 sebagai bagian dari kegiatan penelitian berikut:

**Judul**
Sistem Rekomendasi Cerdas Itinerari (SIRECI) Wisata dan Kuliner Banyuwangi Berbasis Preferensi serta Waktu Kunjungan

**Skema**
Penelitian Fundamental Reguler

**Tim Peneliti**
1. Ayu Purwaningtyas, S.Hut., M.M.
2. Khoirul Umam, S.Pd., M.Kom.
3. Ruth Ema Febrita, S.Pd., M.Kom.

**Afiliasi**
Politeknik Negeri Banyuwangi

**Pendanaan**
Direktorat Penelitian dan Pengabdian Kepada Masyarakat (DPPM)
Direktorat Jenderal Riset dan Pengembangan
Kementerian Pendidikan Tinggi, Sains, dan Teknologi.
